Usage

Above 40px use the ringed mark. 16–40px use the solid cut — the ring's hairlines and the finger joints do not survive below 40.

Clear space equals the radius of one fingertip node on all sides. Never place the ringed mark on a busy field; the outer hairline is 0.75 units and will vanish.

The glow is CSS, not the file. Assets ship flat; apply filter: drop-shadow(0 0 6px #00ff6677) at the usage site so it scales with context.

mark.svg and mark-solid.svg use currentColor — inline them and set color. tile.svg, lockup.svg and favicon.svg carry literal green for <img> use.

Desktop icons are generated, not drawn. npm run icons rasterises build/icons/ (8 PNGs + a 7-entry icon.ico) straight from tile.svg and favicon.svg using Electron's own Blink — no extra dependency. It applies the size rule automatically: 48px and under are cut from the solid hand, 64px and up from the ringed mark. Re-run it after changing either SVG.

The wordmark is Megrim (--font-wordmark), loaded from Google Fonts in index.html. It is live text, so lockup.svg only renders correctly where that font is available — inline in the app, yes; as an <img> in a README, no. Use the mark alone in those places. Megrim is hairline: never set it below 18px, and never use it for UI or running text — that stays Orbitron and Share Tech Mono.
